Hint Ladder

Two Sum 1: Ask what value would complete the current number before deciding where to store it.

Two Sum 2: After each index, the map should represent only usable earlier indices.

Two Sum 3: Scan left to right; return on a seen complement, otherwise record the current value.

Longest Substring 1: Track the earliest valid start of the current duplicate-free substring.

Longest Substring 2: Move the left pointer only past duplicates still inside the current window.

Longest Substring 3: Repair the left boundary, update last seen, then compute the best valid window length.
