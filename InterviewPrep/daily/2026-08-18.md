### Progressive hints

#### Two Sum

- Hint 1 — small directional nudge: Ask what value would complete the current number before deciding where to store it.
- Hint 2 — relevant invariant or data-structure choice: After index `i`, the map should represent only usable earlier indices.
- Hint 3 — high-level approach, still without code: Scan left to right; if the complement was seen, return that earlier index and the current index, otherwise record the current value.

#### Longest Substring Without Repeating Characters

- Hint 1 — small directional nudge: Track the earliest valid start of the current duplicate-free substring.
- Hint 2 — relevant invariant or data-structure choice: The left pointer never moves backward; only jump it past a duplicate if that duplicate is inside the current window.
- Hint 3 — high-level approach, still without code: For each right index, update the last seen position and compute the best valid window length after repairing the left boundary.
