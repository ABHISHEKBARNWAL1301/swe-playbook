# DSA

Personal notes on Data Structures & Algorithms — concepts, patterns, and important practice questions.

## Structure

Each topic lives in its own markdown file at the repo root:

- [graph.md](graph.md) — Graphs (traversal, shortest paths, MST, etc.)
- [trie.md](trie.md) — Tries

More topics will be added over time (arrays, strings, DP, trees, heaps, sliding window, ...).

## Format

Each topic file typically contains:

- **Concept** — definition and core idea
- **Patterns** — common templates / approaches
- **Complexity** — time and space tradeoffs
- **Important questions** — curated problems with notes / links

## Usage

Browse topic files directly, or use them as a quick revision sheet before interviews.
