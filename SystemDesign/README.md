## System Design
Translating requirements into architecture — choosing the right components, trade-offs, and interactions to build systems that scale and stay reliable.

## Core Concepts

**Operating Systems (OS)**
- Processes, threads, scheduling, synchronization
- Memory management — virtual memory, paging, segmentation
- File systems, I/O, inter-process communication

**Database Management Systems (DBMS)**
- Relational & NoSQL databases, indexing, transactions
- Normalization, ACID, query optimization
- Scaling — sharding, replication, partitioning

**Computer Networks (CN)**
- OSI/TCP-IP model, DNS, HTTP/HTTPS, WebSockets
- Load balancers, proxies, CDN, API gateways
- Latency, bandwidth, congestion control

**Object-Oriented Programming (OOPs)**
- Encapsulation, inheritance, polymorphism, abstraction
- SOLID principles, design patterns
- Class & sequence diagrams

## Problems

**High-Level Design (HLD)**
- End-to-end architecture for real-world systems
- Component selection, trade-offs, scalability & reliability decisions

**Low-Level Design (LLD)**
- Class design, API contracts, data models
- Algorithms, concurrency, and design pattern application
